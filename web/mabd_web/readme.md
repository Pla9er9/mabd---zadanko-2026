# Wersja przeglądarkowa aplikacji MABD do zarządzania zadaniami

### Aplikacja umożliwia
- logowanie i rejestrację użytkownika
- listę zadań
- dodawanie i edycję zadań
- filtrowanie (status, kategoria, termin)
- widok szczegółów zadania
- responsywny interfejs

## Uruchamianie 
- `npm install -g @angular/cli` - Jeśli nie masz zainstalowanego Angular Cli
- `npm install` - instaluje zależności
- `ng serve`- uruchamia serwer
