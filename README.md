# MABD

Nowoczesna aplikacja do zarządzania zadaniami dostępna w wersji desktopowej oraz webowej. Projekt umożliwia organizowanie pracy indywidualnej poprzez tworzenie zadań, planowanie terminów oraz monitorowanie postępu realizacji.

---

## Opis projektu

MABD to wieloplatformowa aplikacja typu To-Do / Task Management, której celem jest usprawnienie organizacji codziennych obowiązków System oferuje intuicyjny interfejs oraz rozbudowane możliwości filtrowania i raportowania.

Aplikacja składa się z dwóch głównych części:

- **Aplikacja webowa** – dostępna z poziomu przeglądarki.
- **Aplikacja desktopowa** – przeznaczona dla systemów Windows, macOS oraz Linux.

---

## Główne funkcjonalności

### Zarządzanie zadaniami

- Tworzenie, edycja i usuwanie zadań.
- Dodawanie opisów i notatek.
- Przypisywanie terminów realizacji.
- Ustawianie statusów:
  - Do wykonania,
  - Zakończone,

### Organizacja pracy

- Tworzenie projektów.
- Grupowanie zadań w kategorie.
- Wyszukiwanie i filtrowanie.
- Sortowanie według różnych kryteriów.

### Synchronizacja

- Synchronizacja danych pomiędzy wersją webową i desktopową.
